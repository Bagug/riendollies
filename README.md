# Sistem Informasi Penyewaan Riendollies

Sistem informasi penyewaan perlengkapan dan jasa pernikahan berbasis website.

## Fitur

- Login Admin
- Login Pelanggan
- Penyewaan Online
- Keranjang
- Upload Bukti Pembayaran
- Verifikasi Pembayaran
- Laporan Penyewaan
- Laporan Pembayaran

## Teknologi

- Laravel 11
- PHP 8.3
- SQLite
- Tailwind CSS
- Flowbite
